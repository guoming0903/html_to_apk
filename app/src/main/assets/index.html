📖 操作說明
📅 月曆操作
  • 切換班別：點擊頂部【A / B / C / D 班】切換當前班別。
  • 切換月份：左右滑動月曆畫面，或透過頂部下拉選單選擇年份與月份。
  • 新增/修改備註：點擊任意日期格子，即可開啟視窗輸入備註。
📊 工時統計
  • 切換月份數據：左右滑動統計頁面，即可查看不同月份的工時資料。
⏰ 鬧鐘設定
  • 新增鬧鐘：設定時間、名稱、響鈴時間（當天/前一天）、鈴聲類型及適用班別後點擊【加入鬧鐘】。
  • 開關與刪除：於鬧鐘列表中可隨時切換開關或點擊【✕】刪除鬧鐘。
  • 關閉響鈴：鬧鐘響起時，點擊全螢幕警報上的【確定 / 關閉鬧鐘】即可停止響鈴。
